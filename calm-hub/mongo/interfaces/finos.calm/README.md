# finos.calm Interfaces

The example interface definitions that CALM Hub seeds into the `finos.calm` namespace. They are
copies of `examples/interfaces/example/` in [finos/calm-schema](https://github.com/finos/calm-schema),
which publishes them at the URL in each `$id` (`https://calm.finos.org/interfaces/example/...`).
Update them from there; do not edit them here.

Seeded by `calm-hub/nitrite/init-nitrite.sh` (`create_interfaces`). The name of each interface is
its `title`.
