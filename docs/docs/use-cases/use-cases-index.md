# Use Cases

This section collects real-world examples and community prototypes that show CALM applied to practical problems. Each entry explains the scenario, how CALM is used, and links to the relevant code.

Use these examples to move from the specification to something you can run and adapt.

## Use cases

## Adding a use case

Have a prototype or integration to share? Open a pull request that adds one markdown file to `docs/docs/use-cases/`, and link it in the table above. Each entry should be short and include:

- The problem or scenario the example addresses.
- How CALM is used in it.
- A link to the external GitHub repository.
