# Enterprise Architecture Layers

Adds the **Layers** lens to the **Diagram** tab of CALM Hub. Provided by FINOS CALM. Runs as a
[sidecar](install.md).

Draws an architecture in the ArchiMate® notation, in a **Layered** view or an **Application cooperation**
view. The README of the extension lists how each CALM node type and relationship maps to the notation.

| | |
|:--|:--|
| Port | `8094` |
| Export folder variable | `CALM_EA_LAYERS_EXPORT_DIR` |
| Reads | The architecture only |
| Source | [`calm-hub-extensions/ea-layers`](https://github.com/finos/architecture-as-code/tree/main/calm-hub-extensions/ea-layers) |
